# Phrasebook import (2026-10-11)

Source: the maintainer's own "200 Essential Italian Phrases" PDF (confirmed theirs to use).
Imported as modules `pb-*` (one per section, original numbers kept as item ids p001 to p200) plus `pb-overview`.
Built into `dist/pdf/06-200-Phrases.pdf` and into the app as flashcards.

Edits made on import (everything else is verbatim, with straight apostrophes):
- p015 added the everyday wording as an example (Più piano).
- p017 shows the missing word: Come si dice ... in italiano?
- p025, p027, p073 generalised personal details to placeholders with generic examples
  (was: Vengo dal Pakistan / Università di Messina / bus to Papardo).
- p026 Sono studente (usual with a role); female Sono studentessa.
- p036 was "contratto annuale", now contratto transitorio per studenti (art. 5 legge 431/1998, 6 to 36 months).
- p081, p184 added the female forms.
- p126 added a note that it can sound like a date invitation.
- p148 was "Accettate il passaporto?", now Posso usare il passaporto come documento?
- Rental note: "caparra" is earnest money, the security deposit is deposito cauzionale. The doc's reference to an Agenzia delle Entrate rental guide was left out because the link was not verified.
- Our own pack was corrected the same way (scenario-housing, writing task): see content/ledger/rental-terms.yaml.
